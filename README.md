# Faculty Feedback System

A web-based Faculty Feedback System developed as a Web Programming project.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Features

- Faculty and subject selection
- Star-based rating system
- Feedback comments
- JavaScript form validation
- Dynamic feedback interaction
- Feedback storage using PHP and MySQL

## Project Structure

- index.html – Feedback form
- style.css – Styling
- script.js – JavaScript validation and interaction
- PHP files – Backend processing
- MySQL – Database storage
